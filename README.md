# Death Notices

Shows a notification when a player dies, including the cause and attacker when available.

- **Alex was shot by police.**
- **Sam was shot by Riley.**
- **Jordan was killed in an explosion.**

Unknown causes show a simple **“Alex died.”** Notifications stay on screen for six seconds.

## Installation

Install through **r2modman** or **Thunderstore Mod Manager**.

For manual installation, put `DeathNotices.dll` in your game's `Mods` folder.
Requires **MelonLoader 0.7.3**. **IL2CPP only.**
